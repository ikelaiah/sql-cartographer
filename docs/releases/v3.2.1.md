# v3.2.1 — Free canvas panning

- **Release date:** 13 October 2026.
- **Base:** v3.2.0.
- **Scope:** Recoverable canvas movement in ERD and SQL Flow.

## What changed

- ERD canvas movement works in every direction, including right and down from
  the initial top/left position. Positive viewport offsets provide space before
  the diagram; negative movement uses an extended scroll area.
- ERD **Fit** recentres the complete schema, or a selected table and its declared
  neighbours. Cursor-anchored zoom accounts for the viewport offset. Panning
  moves the view independently of saved table positions.
- SQL Flow distinguishes a drag from a node click. Dragging the canvas or a
  node preserves the requested movement instead of selecting the node and
  reframing the diagram. **Fit overview** recovers the complete chart.
- Diagram controls remain interactive during panning. The user guide explains
  canvas movement, individual table movement, and Fit recovery.

## Verification

An isolated Edge 155 walkthrough reproduced both problems before the fix.
Afterward, an 80-pixel right / 60-pixel downward drag moved both diagrams by
that amount; flow inspection stayed closed. ERD movement beyond the origin,
Fit recovery after a large negative pan, and cursor-anchored zoom were also
observed. The prior browser diagnosis used actual renderer pointer events.

Local TypeScript build, strict pilot, and lint (69 files) passed. The v3.2.1
fixture-corpus metrics snapshot was generated. A separate AI code reviewer
approved the signed viewport coordinates, zoom/Fit calculations, flow click
suppression, and guide changes.

The release requires green **Correctness** and **Firefox smoke** CI on its
complete release commit. Correctness covers generated-runtime freshness,
release-document consistency, local-file startup, golden/fuzz/UI/ERD/security
suites, current metrics, benchmark, and packaged-runtime smoke.
